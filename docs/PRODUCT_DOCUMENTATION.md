# 安语颐年产品文档

## 产品概述

安语颐年是一个基于微信小程序的医疗护理服务平台，专注于为老年人和需要护理服务的用户提供专业的医疗护理、陪诊、居家照护等服务。产品采用前后端分离架构，后端使用Go语言开发，前端为微信小程序，通过微信云托管提供稳定可靠的服务。

## 产品定位

- **目标用户**: 老年人、需要护理服务的患者及其家属
- **核心价值**: 提供专业、便捷、可靠的医疗护理服务
- **服务范围**: 居家照护、医院陪诊、周期护理、家政服务、预约咨询、智慧养老等

## 功能模块

### 1. 用户管理模块

#### 1.1 用户认证
- **微信登录**: 支持微信一键登录
- **用户信息管理**: 昵称、头像、性别等基本信息
- **手机号绑定**: 支持微信手机号一键绑定
- **隐私授权**: 符合微信小程序隐私规范

#### 1.2 用户资料
- **个人资料**: 姓名、性别、年龄、身份证等
- **地址管理**: 支持多个收货地址，默认地址设置
- **就诊人管理**: 支持添加多个就诊人信息
- **紧急联系人**: 紧急情况联系人设置

#### 1.3 权限管理
- **普通用户**: 基础服务使用权限
- **管理员**: 后台管理权限
- **推广员**: 推广和佣金管理权限

### 2. 服务管理模块

#### 2.1 服务分类
- **居家照护**: 上门护理、生活照料、康复训练
- **医院陪诊**: 挂号陪诊、检查陪护、住院陪护
- **周期护理**: 长期护理、定期检查、健康监测
- **家政服务**: 清洁服务、烹饪服务、购物代购
- **预约咨询**: 在线咨询、电话咨询、视频咨询
- **智慧养老**: 智能设备、健康监测、紧急呼叫

#### 2.2 服务详情
- **服务介绍**: 详细的服务描述和特色
- **价格体系**: 基础价格、优惠价格、套餐价格
- **服务时间**: 可预约时间段、服务时长
- **服务范围**: 服务覆盖区域、服务内容
- **评价系统**: 用户评价、服务评分

#### 2.3 服务配置
- **动态表单**: 根据服务类型动态生成预约表单
- **时间槽管理**: 可预约时间段配置
- **价格策略**: 不同时段的差异化定价
- **服务规则**: 服务规则和限制条件

### 3. 订单管理模块

#### 3.1 订单流程
- **服务选择**: 选择服务类型和具体服务
- **信息填写**: 填写预约信息、服务地址、联系人等

- **支付处理**: 微信支付集成
- **订单跟踪**: 实时订单状态更新

- **服务中**: 服务进行中
- **已完成**: 服务完成
- **已取消**: 订单取消
- **已退款**: 订单退款

#### 3.3 订单管理
- **订单列表**: 分页显示用户订单

- **订单操作**: 取消、退款、评价等操作
- **订单搜索**: 按时间、状态、服务类型搜索

## API接口设计

### 接口规范
- **协议**: HTTPS
- **数据格式**: JSON
- **认证方式**: Token认证
- **响应格式**: 统一响应格式

### 核心接口

#### 用户认证接口
- `POST /api/wx/login` - 微信登录
- `GET /api/user/info` - 获取用户信息
- `POST /api/user/bind_phone` - 绑定手机号

#### 服务管理接口
- `GET /api/service/list` - 获取服务列表
- `GET /api/service/categories` - 获取服务分类
- `POST /api/service/detail` - 获取服务详情

#### 订单管理接口
- `POST /api/order/submit` - 提交订单
- `POST /api/order/pay/{id}` - 支付订单
- `GET /api/order/list` - 获取订单列表
- `POST /api/order/detail` - 获取订单详情

#### 支付相关接口
- `POST /api/order/pay/{id}` - 统一下单
- `POST /api/order/refund/{id}` - 申请退款

#### 咨询相关接口
- `POST /api/kefu/send_msg` - 发送消息
- `GET /api/kefu/faq` - 获取常见问题
