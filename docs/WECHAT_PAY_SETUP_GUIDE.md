## 配置步骤

### 1. 微信商户平台配置

#### 1.1 登录商户平台
1. 访问 https://pay.weixin.qq.com/
2. 使用您的微信账号登录
3. 选择商户号 1726638701

#### 1.2 设置API密钥
1. 进入 **账户中心** -> **API安全** -> **API密钥**
2. 点击 **设置API密钥**
3. 设置32位字符串作为商户密钥
4. 记录下这个密钥，稍后需要设置到环境变量中

#### 1.3 配置支付回调地址
1. 进入 **产品中心** -> **开发配置** -> **支付配置**
2. 设置 **支付回调地址** 为: `https://your-domain.com/api/payment/notify`
3. 将 `your-domain.com` 替换为您的实际域名

### 2. 微信小程序平台配置

3. 进入 **微信支付** -> **商户号管理**
4. 点击 **关联商户号**
5. 输入商户号: 1726638701
6. 确认关联

#### 2.2 配置支付域名
1. 进入 **开发** -> **开发管理** -> **开发设置**

## 常见问题

### Q1: 支付调起失败
**可能原因**:
- 商户密钥未正确设置
- 小程序未关联商户号
- 支付参数格式错误

**解决方案**:
1. 检查环境变量是否正确设置
2. 确认小程序已关联商户号1726638701
3. 查看后端日志确认错误信息

### Q2: 支付回调失败
**可能原因**:
- 回调URL配置错误
- 服务器无法接收回调请求
- 签名验证失败

**解决方案**:
1. 确认回调URL可访问
2. 检查服务器防火墙设置
3. 验证签名生成逻辑

### Q3: 商户号格式错误
**错误信息**: "商户号格式错误"
**解决方案**: 确认商户号1726638701为10位数字

## 安全注意事项

1. **保护商户密钥**: 不要将商户密钥提交到代码仓库
2. **使用HTTPS**: 确保所有API调用都使用HTTPS
3. **验证签名**: 所有支付相关请求都要验证签名
