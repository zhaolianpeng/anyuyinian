# 智慧养老设备简化购买流程

## 问题描述

用户反馈智慧养老服务详情页需要填写购买信息，但实际上智慧养老设备是直接购买，不需要复杂的表单填写。

## 解决方案

### 1. 移除购买信息表单

#### 1.1 前端界面调整
- **智慧养老设备**: 不显示购买信息表单
- **普通服务**: 正常显示预约信息表单

```xml
<!-- 预约表单（智慧养老设备不显示） -->
<view class="booking-form" wx:if="{{service.category !== '智慧养老'}}">
  <view class="section-title">预约信息</view>
  <!-- 表单内容 -->
</view>
```

#### 1.2 表单验证简化
```javascript
// 智慧养老设备只需要验证地址
if (service.category === '智慧养老') {
  if (!selectedAddress) {
    wx.showToast({
      title: '请选择收货地址',
      icon: 'none'
    })
    return false
  }
  return true
}
```

### 2. 购买流程对比

#### 2.1 普通服务购买流程
1. 选择患者信息
2. 选择服务地址
3. 填写预约信息表单
4. 选择预约时间
5. 填写备注信息
6. 提交订单

#### 2.2 智慧养老设备购买流程
1. 选择收货地址
2. 填写备注信息（可选）
3. 提交订单

### 3. 界面元素调整

#### 3.1 显示/隐藏逻辑
- ✅ **患者信息选择**: 智慧养老设备不显示
- ✅ **购买信息表单**: 智慧养老设备不显示
- ✅ **预约时间选择**: 智慧养老设备不显示
- ✅ **收货地址选择**: 智慧养老设备显示
- ✅ **备注信息**: 智慧养老设备显示
- ✅ **视频播放**: 智慧养老设备显示

#### 3.2 按钮文案
- **智慧养老设备**: "立即购买"
- **普通服务**: "立即预约"

### 5. 用户体验优化

#### 5.1 简化操作
- 减少用户填写步骤
- 降低购买门槛
- 提高转化率

#### 5.2 清晰区分
- 智慧养老设备：商品购买模式
- 普通服务：服务预约模式

#### 5.3 一致性保证
- 保持地址选择功能
- 保持备注信息功能
- 保持订单跟踪功能

### 6. 技术实现

#### 6.1 前端修改

- `pages/service/detail.js`: 简化表单验证逻辑

#### 6.2 后端支持
- 智慧养老订单API支持空值字段
- 订单模型支持可选字段

#### 6.3 数据库设计
- 订单表字段支持NULL值
- 智慧养老设备订单相关字段为NULL

通过移除智慧养老设备的购买信息表单，实现了极简的购买流程：

- **用户体验**: 大幅简化购买步骤，提高转化率
