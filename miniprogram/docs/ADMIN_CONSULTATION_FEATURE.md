# 管理员在线咨询功能使用说明

## 功能概述

管理员在线咨询功能允许超级管理员查看用户咨询列表，并在线回复用户的咨询消息，提供实时的客户服务支持。

## 功能特性

### ✅ 已实现功能

#### **1. 管理员首页集成**
- **咨询统计显示**：在管理员首页显示待回复咨询数量和总咨询数
- **快捷入口**：在管理功能菜单中添加"在线咨询"入口
- **实时提醒**：待回复咨询数量以红色徽章形式显示

#### **2. 咨询列表管理**
- **状态筛选**：支持按状态筛选咨询（全部、等待回复、咨询中、已结束）
- **实时统计**：显示各状态咨询的数量统计
- **快速操作**：支持回复、关闭咨询等操作
- **下拉刷新**：支持下拉刷新和上拉加载更多

#### **3. 在线回复功能**
- **实时聊天**：管理员可以直接在聊天界面回复用户
- **消息历史**：显示完整的咨询对话记录
- **快捷回复**：提供常用回复语快速选择
- **状态同步**：实时同步咨询状态和消息更新

## 使用流程

### **步骤1：进入咨询管理**
1. 登录管理员账号
2. 在管理员首页点击"在线咨询"菜单项
3. 进入咨询列表页面

### **步骤2：查看咨询列表**
1. 查看咨询统计信息（总咨询数、等待回复数等）
2. 使用筛选标签查看不同状态的咨询
3. 点击咨询项查看详细信息

### **步骤3：回复用户咨询**
1. 点击"回复"按钮或咨询项
2. 进入聊天界面
3. 查看用户消息历史
4. 输入回复内容并发送
5. 实时查看对话更新

### **步骤4：管理咨询状态**
1. 在咨询列表中选择需要关闭的咨询
2. 点击"结束"按钮
3. 确认关闭操作
4. 咨询状态自动更新为"已结束"

## 技术实现

### **前端架构**
```
pages/admin/
├── home.js                    # 管理员首页
├── home.wxml                  # 管理员首页界面
├── home.wxss                  # 管理员首页样式
└── consultation/
    ├── list.js               # 咨询列表页面
    ├── list.wxml             # 咨询列表界面
    ├── list.wxss             # 咨询列表样式
    ├── chat.js               # 咨询聊天页面
    ├── chat.wxml             # 咨询聊天界面
    └── chat.wxss             # 咨询聊天样式
```

### **API接口**
- `GET /api/consultation/stats` - 获取咨询统计
- `GET /api/consultation/active` - 获取活跃咨询列表
- `GET /api/consultation/messages` - 获取咨询消息
- `POST /api/consultation/send` - 发送咨询消息
- `POST /api/consultation/close` - 关闭咨询会话

### **数据流程**
1. **用户发起咨询** → 创建咨询会话 → 发送欢迎消息
2. **用户发送消息** → 更新咨询状态 → 创建通知
3. **管理员查看** → 加载咨询列表 → 显示统计信息
4. **管理员回复** → 发送消息 → 更新状态 → 用户接收

## 权限控制

### **访问权限**
- 只有超级管理员可以访问咨询管理功能
- 普通管理员无法查看咨询相关功能

### **操作权限**
- 查看咨询列表和统计信息
- 回复用户咨询消息
- 关闭咨询会话
- 查看完整的咨询历史记录

## 注意事项

### **使用建议**
1. **及时回复**：建议在收到新咨询通知后及时回复用户
2. **专业回复**：保持专业、友好的回复态度
3. **状态管理**：及时更新咨询状态，避免遗漏
4. **记录保存**：所有对话记录都会自动保存

### **技术注意**
1. **消息轮询**：使用3秒轮询获取最新消息
2. **状态同步**：咨询状态实时同步更新
3. **错误处理**：网络异常时自动重试
4. **资源清理**：页面卸载时自动清理定时器
