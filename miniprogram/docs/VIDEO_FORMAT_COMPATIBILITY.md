# 小程序视频格式兼容性指南

## 问题分析

错误信息 `MEDIA_ERR_SRC_NOT_SUPPORTED` 表明视频格式不被小程序支持。

## 小程序视频格式要求

### 支持的格式
- **容器格式**: MP4
- **视频编码**: H.264
- **音频编码**: AAC
- **分辨率**: 建议不超过1080p
- **文件大小**: 建议不超过10MB

### 不支持的格式
- AVI, MOV, WMV, FLV 等容器格式
- H.265/HEVC 视频编码
- MP3, WAV 等音频编码
- 过大的文件（>50MB）

## 解决方案

### 1. 使用兼容的测试视频
```javascript
// 使用W3C标准测试视频
const testVideoUrl = 'https://media.w3.org/2010/05/sintel/trailer_hd.mp4'
```

### 2. 视频文件优化
如果使用自己的视频文件，需要使用FFmpeg进行转换：

```bash
# 转换为小程序兼容格式
ffmpeg -i input.mp4 \
  -c:v libx264 \
  -profile:v baseline \
  -level 3.0 \
  -b:v 500k \
  -maxrate 1000k \
  -bufsize 2000k \
  -c:a aac \
  -b:a 64k \
  -ar 44100 \
  -ac 2 \
  -movflags +faststart \
  -preset fast \
  -crf 28 \
  -vf "scale=640:360" \
  -t 30 \
  output.mp4
```

### 3. 参数说明
- `-c:v libx264`: 使用H.264编码
- `-profile:v baseline`: 使用baseline profile（兼容性最好）
- `-level 3.0`: 使用level 3.0（支持更多设备）
- `-b:v 500k`: 视频码率500kbps
- `-c:a aac`: 使用AAC音频编码
- `-b:a 64k`: 音频码率64kbps
- `-movflags +faststart`: 优化网络播放
- `-preset fast`: 编码速度预设
- `-crf 28`: 质量参数（18-28，越小质量越好）
- `-vf "scale=640:360"`: 缩放分辨率
- `-t 30`: 限制时长30秒

## 本地视频文件要求

如果要使用本地视频文件，需要：

1. **文件格式**: MP4
2. **编码格式**: H.264 + AAC
3. **文件大小**: < 10MB
4. **分辨率**: 建议640x360或更小
5. **文件位置**: `/video/video.mp4`

## 推荐做法

### 1. 使用在线视频
- 使用CDN托管的兼容视频
- 避免本地文件大小限制
- 更好的加载性能

### 2. 降级模式
- 如果视频播放失败，自动显示封面图
- 保证用户体验不受影响
- 提供备用方案

### 3. 测试验证
- 在真机上测试
- 检查不同网络环境
- 验证播放控制功能

## 总结

小程序对视频格式要求严格，必须使用：
- MP4容器
- H.264视频编码
- AAC音频编码
- 合适的文件大小

通过使用兼容的测试视频，我们可以验证播放功能是否正常工作。
