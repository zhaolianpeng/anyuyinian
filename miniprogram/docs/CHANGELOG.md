### 文件结构
```
miniprogram/
├── pages/                 # 页面文件
│   ├── index/            # 首页
│   ├── login/            # 登录页
│   ├── user/             # 用户中心
│   ├── service/          # 服务相关
│   ├── order/            # 订单相关
│   ├── referral/         # 推荐系统
│   ├── kefu/             # 客服相关
│   ├── hospital/         # 医院相关
│   └── webview/          # 网页视图
├── utils/                # 工具类
│   └── request.js        # 请求封装和模拟数据
├── images/               # 图标文件
│   └── README.md         # 图标说明
├── config.js             # 配置文件
├── app.js                # 应用入口
├── app.json              # 应用配置
├── app.wxss              # 全局样式
├── sitemap.json          # 站点地图
├── README.md             # 项目说明
├── DEVELOPMENT.md        # 开发指南
└── CHANGELOG.md          # 更新日志
```

### 部署说明
1. 确保微信开发者工具已安装
2. 导入项目到微信开发者工具
3. 配置AppID（可选，用于发布）
4. 勾选"不校验合法域名"
5. 测试所有功能正常
6. 提交审核并发布
