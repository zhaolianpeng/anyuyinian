# 定位功能使用指南

## 功能概述

安语颐年小程序提供智能定位功能，帮助用户自动获取当前位置，并根据位置信息提供相应的服务。即使用户关闭定位权限，也可以通过手动选择城市来使用服务。

## 主要特性

### 1. 自动定位
- **启动即定位**: 小程序启动时自动获取用户位置
- **智能权限管理**: 自动处理定位权限申请
- **实时更新**: 根据GPS信号实时更新位置信息
- **超时保护**: 10秒超时机制，超时后自动提供手动选择

### 2. 手动城市选择
- **分类城市列表**: 按地区分组显示城市选项
- **热门城市优先**: 常用城市排在前面
- **快速切换**: 一键切换不同城市

### 3. 智能错误处理
- **权限拒绝**: 引导用户开启权限或手动选择
- **定位失败**: 提供重新定位和手动选择选项
- **网络异常**: 智能识别网络问题并给出建议

## 使用方法

### 自动定位流程

1. **首次使用**
   - 小程序启动时自动申请定位权限
   - 用户允许后开始GPS定位
   - 显示"定位中(10s)..."倒计时
   - 10秒内获取位置后显示当前城市
   - 超时后自动提供手动选择城市选项

2. **权限管理**
   - 如果用户拒绝定位权限，显示引导弹窗
   - 提供"去设置"和"手动选择"两个选项
   - 用户可以在设置中重新开启定位

3. **定位成功**
   - 显示"📍"图标和城市名称
   - 自动保存定位信息
   - 根据城市更新相关服务

### 手动选择城市

1. **点击城市名称**
   - 在首页左上角点击城市名称
   - 弹出城市选择列表

2. **城市分类**
   - **热门城市**: 北京、上海、广州、深圳等
   - **华北地区**: 北京、天津、石家庄等
   - **华东地区**: 上海、南京、杭州等
   - **华南地区**: 广州、深圳、佛山等
   - **华中地区**: 武汉、长沙、郑州等
   - **西南地区**: 成都、重庆、昆明等
   - **西北地区**: 西安、兰州、西宁等

3. **选择操作**
   - 点击"📍 重新定位"可重新尝试GPS定位
   - 点击具体城市名称直接选择
   - 选择后自动保存并更新显示

## 错误处理

### 定位超时
- **原因**: 网络较慢或GPS信号弱
- **超时时间**: 10秒自动超时
- **倒计时显示**: 实时显示剩余时间
- **解决方案**: 超时后自动提供手动选择城市选项

### 定位失败
- **原因**: GPS信号较弱或网络问题
- **解决方案**: 到开阔地带重试或手动选择

### 权限被拒绝
- **原因**: 用户在系统设置中关闭了定位权限
- **解决方案**: 引导用户到设置中开启权限

### 网络异常
- **原因**: 网络连接不稳定
- **解决方案**: 检查网络设置后重试

## 数据存储

### 本地存储
- **userSelectedCity**: 用户选择的城市名称
- **citySelectionType**: 城市选择类型（auto/manual）

### 数据优先级
1. **手动选择**: 用户手动选择的城市（最高优先级）
2. **自动定位**: GPS自动获取的城市
3. **默认城市**: 系统默认的北京
