- 视频文件已更新到腾讯云对象存储
- 使用临时URL获取视频地址
- 直接播放，不进行格式验证

- 如果播放失败，自动启用降级模式
- 显示封面图片作为备用方案
- 确保用户体验不受影响

## 优化建议

### 1. 视频文件优化
如果视频播放有问题，可以使用FFmpeg优化：

```bash
# 优化视频文件
ffmpeg -i input.mp4 \
  -c:v libx264 \
  -profile:v baseline \
  -level 3.0 \
  -b:v 500k \
  -c:a aac \
  -b:a 64k \
  -movflags +faststart \
  -preset fast \
  -crf 28 \
  -vf "scale=640:360" \
  -t 30 \
  output.mp4
```

### 2. 性能优化
- 视频文件大小建议 < 10MB
- 分辨率建议 640x360 或更小
- 使用H.264 + AAC编码
