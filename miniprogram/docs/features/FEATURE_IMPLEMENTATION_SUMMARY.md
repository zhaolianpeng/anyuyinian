# 小程序功能实现总结

## 已实现功能

### 1. 地址管理功能

#### 前端实现
- **地址列表页面** (`pages/user/address/list`)
  - 显示用户所有地址
  - 支持编辑和删除操作
  - 支持选择地址模式（用于订单页面）
  - 空状态和加载状态处理
  - 下拉刷新功能

- **地址添加/编辑页面** (`pages/user/address/add`)
  - 完整的表单验证
  - 地区选择器
  - 默认地址设置
  - 支持编辑现有地址

#### 后端接口
- `GET /api/user/address` - 获取地址列表
- `POST /api/user/address` - 创建地址
- `PUT /api/user/address` - 更新地址
- `DELETE /api/user/address` - 删除地址

#### 功能特点
- 完整的CRUD操作
- 表单验证（姓名、手机号、地址等）
- 默认地址管理
- 与订单系统集成

### 2. 就诊人管理功能

#### 前端实现
- **就诊人列表页面** (`pages/user/patient/list`)

  - 支持选择就诊人模式
  - 显示关系标签和默认标识

- **就诊人添加/编辑页面** (`pages/user/patient/add`)

  - 身份证号验证
  - 性别和关系选择器
  - 出生日期选择器
  - 默认就诊人设置

#### 后端接口
- `GET /api/user/patient` - 获取就诊人列表
- `POST /api/user/patient` - 创建就诊人
- `PUT /api/user/patient` - 更新就诊人
- `DELETE /api/user/patient` - 删除就诊人

#### 功能特点
- 完整的就诊人信息管理
- 身份证号格式验证
- 多种关系类型支持
- 与医疗服务集成

## 数据库设计

### 地址表 (user_addresses)
```sql
- id: 主键
- user_id: 用户ID
- name: 联系人姓名
- phone: 手机号
- province: 省份
- city: 城市
- district: 区县
- address: 详细地址
- is_default: 是否默认地址
- created_at: 创建时间
- updated_at: 更新时间
```

### 就诊人表 (user_patients)
```sql
- id: 主键
- user_id: 用户ID
- name: 姓名
- id_card: 身份证号
- phone: 手机号
- gender: 性别
- birthday: 出生日期
- relation: 与本人关系
- is_default: 是否默认就诊人
- created_at: 创建时间
- updated_at: 更新时间
```

### 客服消息表 (kefu_messages)
```sql
- id: 主键
- user_id: 用户ID
- user_name: 用户姓名
- user_avatar: 用户头像
- type: 消息类型（0:客服, 1:用户）
- content: 消息内容
- images: 图片列表（JSON）
- status: 消息状态
- created_at: 创建时间
```
